# Backend Developer Test

REST API for product management built with ASP.NET Core 10, PostgreSQL, Entity Framework Core, JWT Authentication, Swagger, and Docker.

## Features

- Product CRUD
- Product search
- Product category filter
- Pagination
- User registration
- User login
- JWT authentication
- Refresh token generation
- Authorization for create, update, and delete product
- Swagger API documentation
- PostgreSQL database
- Docker support
- CORS support

## Run with Docker

docker compose up --build
